# Native Android screens for the first release

Build native Android screens for player ratings, player profiles, and match
results to provide Android navigation and controls. Embedding the existing
website would be quicker to deliver, but the project owner chose the native
experience despite the additional data-integration work. The website backend's
source code is unavailable; data access is defined in
[the direct-access decision](0002-direct-website-data-access.md).
